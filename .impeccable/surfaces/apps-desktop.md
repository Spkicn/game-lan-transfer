# Surface: 桌面应用主流程（连接 → 选择内容 → 传输）

## Scope & mode

Operate。这是一个要干活的窗口：用户来把游戏或文件夹搬到另一台机器。表达不得妨碍任务、状态与既有习惯，品牌只活在精确的细节里。

## Audience & job

公开发布的不特定用户：有两台 Windows 机器的玩家，会给笔记本下游戏、会插网线，但不懂子网掩码、共享、ACL，也不愿看命令行。job：把已经下好的内容搬到另一台机器，落地后启动器直接认领，不重新下载。

## Action / task

单一主线三个阶段：① 确认与对端的连接（自动发现 + 一键连接，配对码可选）② 选择要传的内容（平台游戏，或任意文件夹与文件）③ 发起传输，接收端看到请求、选目标目录、点同意之后才落盘。高频状态不是"没有内容"，而是"正在传、传了一半、断了、空间不够"。

## Proof / content

真实内容：本机扫描出的游戏（名称、平台、体积、版本指纹）、本机目录里的文件树、传输速度与剩余时间、目标盘剩余空间、失败原因。空状态说清楚下一步该做什么，不编造数据，不用占位符假装有内容。

## Constraints

Windows 桌面窗口，默认 1100×760、最小 900×620；中文界面，不出现 SMB、ACL、子网掩码这类词；接收方同意前不落盘；中断必须能续；键盘可达；只用 shadcn/ui + Tailwind 的既有语义与组件，不引入第二套设计语言，也不搭一层自研组件库。

硬约束（用户确认）：Rust 引擎的既有行为与 CLI 命令全部保留，新流程只能以新增能力的方式叠加，不得改动既有公开 API 的语义。

反面清单（用户确认，任何一条都算做错了）：
- 看起来像游戏启动器，或花哨的动效与装饰插图；
- 术语堆砌、整屏工程表格让人读不懂；
- 为了好看牺牲状态可见性——速度、剩余时间、文件路径必须始终在场。

## Chosen direction

本地 grounded 列表第 3 条：**机房配线架（patch panel / switch port）**。seed key `f52c0d33`。

## Memorable moment

插上跳线的那一下：两个端口之间的折线亮起，端口下方的链路速率与两端地址同时出现——用户第一次"看见"两台机器连上了。

## Unresolved decisions

战网 / EA / Ubisoft / GOG 适配器是否进这一版；接收端同意是否需要二次确认（例如目标目录非空时）；是否记住上次对端。

## Direction contract

THESIS：把"两台机器搬到一起"画成一块配线架——本机与对端是两个端口，中间的跳线就是链路，一切状态由端口灯与跳线走向表达。拒绝的类别默认：把连接画成"设备列表 + 连接按钮"。

OWN-WORLD：深色机架面板底，端口是圆角方孔，状态灯用四种颜色（琥珀=等待、青绿=链路就绪、蓝=传输、红=失败），端口标签小号等宽字，跳线走 45°/90° 折线，所有数字等宽表格数字。控件是面板上的开关与端口，不是网页按钮；卡片与阴影一律不用。

STORY：打开就看到本机端口与"等着接上的那一端"；点一下，跳线接上、端口灯亮，链路速率与两端地址落到端口下方；接着才出现内容选择——游戏或文件夹以行挂在端口一侧，选中即待发；对端在另一台机器上看到同一条目、选目录、点同意，端口进入传输态，行内数字逐位翻动；完成后端口回到就绪，给出启动器认领的收尾。

FIRST VIEWPORT：一块等宽带状面板铺满窗口。左三分之一是本机端口：机器名、端口灯、地址与链路速率；右三分之一是对端端口：未连接时是空插槽加一行"等待跳线"；中间三分之一是跳线与唯一的当前动作。面板下沿一条贴地状态条，只写此刻该做的一件事（如"把跳线接到对端"）。主操作是面板上的物理开关，位于中线下方，不是悬浮按钮。

FORM：本地 grounded 列表第 3 条（按共鸣排序的交换机端口面板），seed key `f52c0d33`；被三处捐赠抬升——
- RAISE · 出发牌：队列每行是按列对齐的实体，状态只重排该行的翻牌，不破网格；字节数逐位翻动，而不是给进度条外挂百分比。
- RAISE · 醋酸页索引板：三个阶段做成阶梯页签，当前页签伸长即当前面板，切换是 90ms 两帧阶跃，不做缓动。
- RAISE · 午夜地铁线路图：两端之间的链路按 45°/90° 折线绘制，传输中只聚焦这条走廊并保留两端上下文；暂停与失败用线路状态色，不弹模态。
- RAISE · 舞蹈记谱：剩余时间以长度表达，行内传输带长度与 ETA 成正比，读数与图形同源。
- RAISE · 像素字样标本：数字只用整数倍等宽表格数字，缩放走整像素，不做亚像素字重。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
